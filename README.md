# Tip Calculator

A single-page tip calculator. Enter a bill, pick a tip, and optionally split the total between people.

Open `index.html` in a browser. There is no build step or install.

## Features

- Bill amount, tip percent, and party size
- Preset tips of 10%, 15%, 18%, 20%, and 25%, plus a custom percent
- Live tip, grand total, and per-person share (rounded to the nearest cent)
- Dark mode toggle (remembers your choice; follows system theme on first visit)
- Validation for empty, negative, or invalid values

## Usage

1. Enter the bill amount in dollars.
2. Choose a tip preset or type your own percent.
3. Set **Split between** if more than one person is paying.
4. Read the tip, total, and each person’s share.

Amounts update as you type.
